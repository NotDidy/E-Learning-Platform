Lesson Details

Introduction to Python Programming

Lesson ID: L001

This lesson introduces students to the fundamentals of Python Programming, including data types, variables, basic operators, and the structure of simple programs. Students will gain confidence in writing simple scripts and understanding how Python executes code step by step.

Objectives

  • Understand Python syntax and indentation
  • Learn variables, constants, and data types
  • Perform input/output operations
  • Write simple Python scripts

Reading List

  • 📘 Python Crash Course - Chapter 1
  • 📗 Official Python Tutorial - Sections 1–3
  • 📕 Think Python - Chapter 2

Prerequisites

None

Assignments

  • Basic Operations Program
  • Variable Practice Exercises
  • Mini Project: Simple Calculator
Duration: 3 hours
Credits: 3
